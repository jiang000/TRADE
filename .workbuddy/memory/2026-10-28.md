## TRADE 仓库改造成 GitHub Pages 博客

- 目标：把 TRADE 仓库（35 篇投资/期权阅读笔记）发布为个人博客，首页为「文章名称超链接瀑布流」。
- 方案：GitHub Pages 原生 Jekyll（无需本地 Ruby）。新建/改动文件：
  - `_config.yml`（站点标题「交易随笔」、baseurl=/TRADE、默认布局 default、排除 README/tools）
  - `_layouts/default.html`（统一布局 + 瀑布流 CSS，文章页按 `page.pubdate` 判断是否显示标题头）
  - `index.html`（首页：Liquid 遍历 `site.pages`，按 `pubdate` 倒序，CSS columns 瀑布流）
  - `404.html`、`README.md`
  - `tools/update_frontmatter.py`（幂等脚本：给文章批量补 `title`/`layout: default`/`pubdate`）
- 35 篇 .md 全部注入 front matter（title/layout/pubdate，各 +3 行），author/date 原样保留。
- 关键设计：用自定义 `pubdate`（字符串 YYYY.MM.DD）做排序/展示，避免 Jekyll 对 `date` 字段的解析歧义。
- git：已提交并 push 到 origin/master（先合并了远程的模板 README，保留本地详细版）。
- 待办：用户需在 GitHub 仓库 Settings → Pages 里选择 Deploy from branch（master / root）启用 Pages，站点地址 https://jiang000.github.io/TRADE/。
- 后续新增文章：跑 `python tools/update_frontmatter.py` 即可补全字段自动上首页。
